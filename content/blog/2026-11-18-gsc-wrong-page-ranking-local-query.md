You expected your location page to appear for a local search, but Search Console shows impressions for your homepage instead. Before changing either URL, check which page Google shows and whether the searcher would be better served by the other one.

## Find the query and the pages it reached

Open Search Console’s [Performance report](https://support.google.com/webmasters/answer/7576553). Filter to the exact query, then open the Pages tab. Compare impressions and positions over the same period for each URL. If there are only a handful of impressions, broaden the period before drawing conclusions. Search results can vary by device and location.

## Give each page a distinct purpose

The homepage should explain the business overall. A useful location page answers coverage, delivery and examples for that market. Compare the titles, main headings and links that point to both pages. Use descriptive links from your locations index and relevant service pages, and make each page’s purpose clear. Check indexing and the canonical URL using URL Inspection if the expected page barely appears.

Record what you changed and review the same query and pages later. If the homepage already answers the query well and leads to enquiries, keep that in mind before making a structural change.
