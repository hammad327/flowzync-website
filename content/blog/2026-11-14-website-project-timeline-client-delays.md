A redesign can sit still for a week over a single decision. The designer is waiting for the price list. The owner assumes the designer is writing it. Both are busy and neither realises the other is waiting.

## Give each dependency an owner

Before you agree a launch date, list the items someone must supply or approve. Website copy, photography, legal text, domain access and CRM credentials are common examples. Give each one an owner and a date. Ask for a working login early where appropriate, using the provider’s access-sharing feature.

Set one approval window for each milestone. If three people need to comment on the homepage, ask one person to consolidate their feedback. Keep a list of decisions still open so people can see the difference between a question and a requested change.

## Plan what can move independently

While photos are pending, a team can often finish the navigation and page structure. A booking integration may need to be tested early if its limitations affect the design. Agree which features are required to launch and what can be added later.
